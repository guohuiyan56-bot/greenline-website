# GREENLINE · 中远海运 COSCO 物流自动转发 — 部署说明

## 整体架构

```
客户(官网 greenlineint.com / track.html)
   │  输入 订单号 或 提单号/订舱号/箱号
   ▼
Cloudflare Worker（greenline-cosco-proxy）  ← 密钥(ApiKey/SecretKey)只存在这里
   │  ① 用 Hmac 体系对请求签名
   │  ② 调用 COSCO 官方接口
   │     https://api.lines.coscoshipping.com/service/info/tracking/{单号}?numberType=bl|bkg|cntr
   │  ③ 把轨迹归一化成干净 JSON
   ▼
官网前端渲染时间线（站内直接显示，不跳走）
```

为什么需要这个 Worker：GitHub Pages 是纯静态站，浏览器受 CORS 限制无法直接读取 COSCO；
且 COSCO 接口要求 Hmac 签名（密钥绝不能放前端）。Worker 在服务端完成转发与签名，安全且跨域可用。

---

## 第一步：获取 COSCO COP 密钥（免费，需审核）

1. 打开 https://cop.lines.coscoshipping.com/#/ 注册「统一账号」。
2. 申请成为开发者（入驻申请），按提示填业务信息。
3. 等待审核（官方说明最长 15 个工作日，试运行期免费）。
4. 审核通过后，**ApiKey / SecretKey 会发到你的注册邮箱**。
   - 若 SecretKey 泄露，在门户「申请重置 HMAC」。

> 配额：试运行期免费，每账号 **每天 1000 次 / 每月 30000 次**。

---

## 第二步：部署 Cloudflare Worker（免费）

1. 注册免费 Cloudflare 账号：https://dash.cloudflare.com/sign-up
2. 本机安装 Wrangler（Node 环境）：
   ```
   npm install -g wrangler
   wrangler login          # 浏览器授权你的 Cloudflare 账号
   ```
3. 进入 `cosco-proxy/` 目录，部署：
   ```
   wrangler deploy
   ```
4. 注入密钥（**不要写进代码**，用 secret 注入）：
   ```
   wrangler secret put COSCO_API_KEY     # 粘贴邮件里的 ApiKey
   wrangler secret put COSCO_SECRET_KEY   # 粘贴邮件里的 SecretKey
   ```
5. 部署成功后会得到一个地址，形如：
   `https://greenline-cosco-proxy.<你的子域>.workers.dev`
   复制这个地址。

---

## 第三步：把 Worker 地址填进官网

打开 `track.html`，把顶部的占位地址改成你的 Worker 地址：

```js
var COSCO_WORKER_URL = 'https://greenline-cosco-proxy.xxx.workers.dev';
```

---

## 第四步：准备历史订单映射（用于「按订单号」查询）

编辑站点根目录的 `orders.json`，把你真实的订单填进去：

```json
[
  {
    "orderNo": "PO2026-001",   // 客户在官网输入的订单号
    "blNo":    "6412690220",   // 提单号（填了就用 bl 查）
    "bkgNo":   "",             // 订舱号（blNo 空时改用 bkg）
    "cntrNo":  "CBHU4398907",  // 箱号（都空时改用 cntr）
    "customer":"客户名(可选)",
    "remark":  "备注(可选)"
  }
]
```

> 说明：该文件随静态站公开可下载。客户只知道自己的订单号，乱猜概率低，通常可接受；
> 若订单号属半机密，需改为放在 Worker 侧或后端数据库（另行评估）。

## 联调时注意（若返回 401）

Worker 已按 COP 文档实现 Hmac 签名。若用真实密钥联调仍返回 401，最可能是
**签名串里的 request-line 是否应包含 `?numberType=...` 这一段**：
- 当前实现：包含 query（与真实请求一致）。
- 若 COSCO 要求不含 query，把 `worker.js` 中 `buildHmacHeaders` 的
  `requestLine` 改为 `GET /service/info/tracking/{number} HTTP/1.1` 即可。
- 另一处可变量：`X-Coscon-Digest` 在 GET 下取空内容 SHA-256；若 COSCO 要求不同，按邮件/文档调整。

如有疑问，把返回的完整错误贴给我，我帮你定位。
